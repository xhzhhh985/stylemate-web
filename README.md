# StyleMate Web

StyleMate 是一个以个人数字衣橱为基础的 Web 穿搭助手。

项目将逐步实现衣物管理、搭配组合、社区分享，以及调用现有 AI API 完成衣物识别和搭配建议。

## 当前阶段

- `v0.1.0`：初始化 Web 项目工程
- `feat/auth-wardrobe`：用户表迁移与可审核的前端页面 Demo（开发中）

## 查看页面 Demo

在 `frontend` 文件夹运行 `npm install`（首次）和 `npm run dev`，打开终端显示的本地地址。

Demo 可录入单件衣物或整套穿搭（整套照片或至少两件衣橱单品），用颜色、品类、季节关键词搜索搭配，并打开完整详情查看图片和标签。社区能浏览预设穿搭，以及当前浏览器选择发布的穿搭。衣橱和穿搭数据仅保存在当前浏览器（单张图片限 1 MB）；其他用户看不到本机发布内容。商品图入口需要手动选择标签；账号、云端存储和跨用户社区尚未接入。

前端验证：在 `frontend` 文件夹运行 `npm test` 和 `npm run build`。
