# StyleMate Web

StyleMate 是一个以个人数字衣橱为基础的 Web 穿搭助手。

项目将逐步实现衣物管理、搭配组合、社区分享，以及调用现有 AI API 完成衣物识别和搭配建议。

## 当前阶段

- `v0.1.0`：初始化 Web 项目工程
- `feat/auth-wardrobe`：用户表迁移与可审核的前端页面 Demo（开发中）

## 查看页面 Demo

在 `frontend` 文件夹运行 `npm install`（首次）和 `npm run dev`，打开终端显示的本地地址。

Demo 可体验衣橱筛选与录入、图片卡片选衣、三种搭配入口、社区页面和个人资料页面。衣橱图片及数据仅保存在当前浏览器（演示图片限 1 MB）；商品图入口需要手动选择标签；账号和云端数据尚未接入。
